![Platform Windows](https://img.shields.io/badge/Platform-Windows-0078D6)

A clean, standalone **PySide6** graphical interface built around the existing [`main.py`](../main.py) rehabilitation application.

The GUI acts **strictly as a visual display layer and session launcher** on top of a single `RehabApplicationController` instance. It does **not** duplicate sensor acquisition, quaternion math, calibration, dynamic IMU alignment, MediaPipe Vision calculations, or Unscented Kalman Filter (UKF) fusion.

## ✨ What the GUI Does

- **Embedded Live Camera & MediaPipe Feed:** Displays the mirrored webcam stream with MediaPipe pose landmarks and skeleton directly inside the window (`show_opencv_window=False` suppresses any separate OpenCV popup window).
- **Live Joint Telemetry:** Displays real-time Shoulder, Elbow, and Trunk measurements, including **Vision angles**, **Raw calibrated IMU angles**, **Dynamically aligned IMU angles**, **Fused UKF angles**, and **UKF angular velocities**.
- **Verbatim `main.py` Telemetry Mirror:** Displays the exact 6-line (during calibration) and 8-line (after calibration) telemetry strings formatted with `rehab_app.vision.fmt`.
- **Sensor & Calibration Monitoring:** Shows Delsys connection status, Sensor 1 & Sensor 2 mode/phase metadata, live raw `(W, X, Y, Z)` quaternions, calibration progress (`0%` → `100%`), and captured Shoulder & Elbow Vision calibration references.
- **Session Recording & Plot Viewer:** Automatically loads exported 4-sheet Excel workbooks (`recordings/*.xlsx`), displays the `Metrics` sheet table, and renders the 7 diagnostic Matplotlib PNG plots generated by `SessionAnalyzer`.

---

## 🔗 How It Interacts with `main.py`

1. **Single Application Instance:** [`gui_main.py`](../gui_main.py) creates one `RehabConfig(..., show_opencv_window=False)` and one `RehabApplicationController`.
2. **Real Hardware Sessions (Default):** Clicking **Start Session** runs the exact `main.py` lifecycle on a single background thread (`MainAppSessionRunner`):
   - `controller.start_experiment()`
   - `controller.wait_for_session(duration_seconds=cfg.record_seconds)`
   - `controller.stop_experiment(export_recording=True, run_analysis=True)`
3. **Simulation Sessions (Explicitly Enabled Only):** When `--simulate` is passed or the **Simulation Mode (`--simulate`)** checkbox is checked before starting, `ApplicationOutputBridge` calls `main.run_live_webcam_with_simulated_sensors()` (or `main.run_simulated_experiment()` if `--no-vision` is set) directly from [`main.py`](../main.py). No simulated sensor data is generated inside `rehab_monitor_gui/`.
4. **Clean Stop & Export:** Clicking **Stop & Export** signals `controller._stop_event.set()`, allowing `wait_for_session()` to exit cleanly into the runner's `finally` block so the Excel workbook and 7 analysis plots are exported exactly once without freezing the Qt UI.

## 📡 Data Flow Architecture

```text
[Existing main.py / RehabApplicationController] (Single Instance, show_opencv_window=False)
   ├── DelsysSensorManager  ──► CalibrationManager (30 s warm-up + 5 s neutral avg)
   ├── PoseVisionProcessor  ──► MediaPipe landmarks + 2D Shoulder/Elbow Vision angles
   ├── JointFusionPipeline  ──► Dynamic IMU alignment (Vision_ref + sign * IMU_rel) + UKF
   └── SessionRecorder      ──► RawData / ProcessedData / Metrics / Settings (.xlsx)
                    │
                    │  Read-only 30 Hz QTimer poll
                    │  • controller.get_current_measurements()
                    │  • controller.get_sensor_status()
                    │  • controller.get_latest_frame()
                    │  • controller.get_completed_results()
                    │  • controller.sensor_manager.get_reading_snapshot(1 | 2)
                    ▼
[rehab_monitor_gui/bridge.py: ApplicationOutputBridge]
                    │  Emits TelemetrySnapshot & SessionResults via Qt Signals
                    ▼
[rehab_monitor_gui/main_window.py: RehabMonitorWindow]
   ├── Tab 1: Live Rehabilitation Dashboard (VideoFeedPanel | JointMeasurementsPanel | StatusAndRecordingPanel)
   └── Tab 2: Session Recordings & Plots   (SessionResultsPanel)
```

## 🖼️ GUI Layout & Displayed Information

### Top Control & Status Bar
- **Branding:** Delsys logo (`Images/delsys.png`, if present) and application title.
- **Session Controls:**
  - **Simulation Mode (`--simulate`)** checkbox (locked while a session is running).
  - **Start Session** — starts sensor streaming, webcam/MediaPipe tracking, warm-up, neutral calibration, and recording.
  - **Stop & Export** — stops the session cleanly, exports the 4-sheet `.xlsx` workbook, and generates the 7 analysis PNG plots.
  - **Reset Calibration** — restarts warm-up and neutral calibration (`controller.reset_calibration()`).
  - **Reset Session** — clears buffered session state when idle (`controller.reset_session()`).
- **Live State Pill:** `● Standby`, `● Calibrating`, `● Calibrated & Active`, or `● Exporting Excel...`.

### Tab 1 — Live Rehabilitation Dashboard (3-Column Layout)

| Column | Widget | Displayed Information |
| :--- | :--- | :--- |
| **Left** | `VideoFeedPanel` | Live MediaPipe-annotated camera feed, Vision status badge, color-coded **Posture Status** banner (`START POSITION (Ready)`, `RIGHT`, `WRONG ...`, `NO POSE DETECTED`), and **Live `main.py` Telemetry Output** verbatim mirror. |
| **Center** | `JointMeasurementsPanel` | **Shoulder Card:** Vision, IMU 1 Pitch (Raw), IMU 1 Pitch (Aligned), Shoulder UKF, UKF Velocity, Shoulder Vision Ref badge.<br>**Elbow Card:** Vision, IMU 1 Yaw (Raw), IMU 1 Yaw (Aligned), Elbow UKF, UKF Velocity, Elbow Vision Ref badge.<br>**Trunk Card:** IMU 2 Pitch / Trunk (direct unfused). |
| **Right** | `StatusAndRecordingPanel` | **Delsys Stream Card:** Connection status, Sensor 1 & Sensor 2 names/modes/phases, live raw `(W, X, Y, Z)` quaternions.<br>**Calibration Card:** Status text, `0%–100%` progress bar, captured Shoulder & Elbow Vision references.<br>**Experiment & Recording Card:** Session state, elapsed time (`MM:SS.s`), recorded sample count, output folder, and last exported workbook name. |

### Tab 2 — Session Recordings & Plots
- **`SessionResultsPanel`:** Lists all `.xlsx` workbooks in `recordings/` (newest first), displays the `Metrics` sheet in a read-only table, and previews any of the 7 generated diagnostic PNG plots (`shoulder_angles_comparison`, `elbow_angles_comparison`, `trunk_angle`, `shoulder_differences`, `elbow_differences`, `ukf_kalman_gains`, `ukf_consistency_distributions`).

## ⚙️ Prerequisites & Installation

1. **Operating System & Python:** Windows with Python 3 (verified on **Python 3.13**).
2. **Required Files in the Project Root:**
   - `pose_landmarker_full.task` (MediaPipe PoseLandmarker model).
   - `resources/DelsysAPI.dll` and `AeroPy/` (required for physical Delsys Trigno hardware).
3. **Install Dependencies** from the `Python/` root directory:
   ```powershell
   pip install -r requirements.txt
   ```
   Packages installed from [`requirements.txt`](../requirements.txt): `PySide6`, `Vispy`, `Scipy`, `pythonnet`, `numpy`, `opencv-python`, `mediapipe`, `pandas`, `openpyxl`, `matplotlib`.

## 🚀 Launching the GUI

Run any of the following commands from the `Python/` directory:

- **Standard Launch (Real Delsys Trigno Hardware + Live Webcam):**
  ```powershell
  python gui_main.py
  ```
  *(Equivalent commands: `python main_gui.py` or `python main.py --gui`)*

- **Launch with Simulation Mode Pre-Selected & Fast Warm-Up (No Delsys Hardware Needed):**
  ```powershell
  python gui_main.py --simulate --warmup 3 --calibration 2
  ```

- **Launch and Auto-Start Immediately:**
  ```powershell
  python gui_main.py --simulate --warmup 3 --calibration 2 --auto-start
  ```

- **Launch Without Camera (Sensor-Only / Headless-Vision Test):**
  ```powershell
  python gui_main.py --simulate --no-vision --warmup 2 --calibration 1 --duration 5
  ```

## 🎛️ CLI Configuration Options

All options accepted by [`gui_main.py`](../gui_main.py) and [`main_gui.py`](../main_gui.py):

| Flag | Default | Description |
| :--- | :--- | :--- |
| `--duration <seconds>` | `3000.0` | Maximum session recording duration in seconds. |
| `--warmup <seconds>` | `30.0` | Stationary sensor warm-up duration before calibration begins. |
| `--calibration <seconds>` | `5.0` | Neutral calibration window for averaging quaternions and Vision references. |
| `--camera-index <int>` | `0` | OpenCV webcam index. |
| `--no-sensors` | `False` | Disable Delsys sensor connection. |
| `--no-vision` | `False` | Disable webcam and MediaPipe vision worker. |
| `--simulate` | `False` | Pre-select `main.py`'s built-in simulation mode. |
| `--auto-start` | `False` | Start the session automatically as soon as the window opens. |

## 🛠️ Troubleshooting

| Issue | Cause | Solution |
| :--- | :--- | :--- |
| **`ModuleNotFoundError: No module named 'PySide6'` (or `numpy`, `cv2`, `mediapipe`)** | Running a Python interpreter that does not have `requirements.txt` installed. | Run `pip install -r requirements.txt` with the same Python executable you use to launch `gui_main.py`. |
| **`DELSYS ERROR: Error, no RF subsystem found`** | Delsys Trigno USB RF receiver is not plugged in or sensors are powered off. | Connect the Delsys base station and power on both paired sensors, or check **Simulation Mode (`--simulate`)** to test without hardware. |
| **`IMU 1 Pitch (Aligned)` or `IMU 1 Yaw (Aligned)` shows `None` after calibration** | The patient's arm/torso was not detected by MediaPipe during the 5 s neutral calibration window, so Vision references could not be averaged. | Ensure the right hip, shoulders, elbow, and wrist are clearly visible during the neutral calibration window, then click **Reset Calibration**. |
| **`CAMERA ERROR: Cannot open camera 0`** | Another application is using the webcam or the camera is on a different index. | Close other camera apps or pass `--camera-index 1` (or the appropriate index). |
| **Running GUI automated tests without a display** | Qt requires an offscreen platform plugin in headless terminals. | `tests/test_rehab_monitor_gui.py` automatically sets `QT_QPA_PLATFORM=offscreen`. Run `python -m unittest tests.test_rehab_monitor_gui -v`. |
